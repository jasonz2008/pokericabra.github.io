Privacy, plainly.

Drawply v0.4.2 · Updated October 12, 2026

This notice describes the Drawply skill, plugin, and distribution pages. It does not replace the separate policies for the Pokericabra game or your AI host. Drawply is an open-source project maintained under the GitHub account jasonz2008.

The short version

Drawply adds no account system, advertising SDK, analytics tracker, or image-upload server. That does not mean everything stays on your device: using it inside an AI host can expose images, annotations and file paths to that host.

What the plugin handles

DataWhat happens
Source image & pathThe renderer reads the image you or your agent selects and writes a review HTML file containing the image and its local source path. For source-backed selection, it also embeds the supplied element hierarchy, text, geometry, colors and referenced local image layers.
Drawing & textMarks are edited in the review. When the host provides a widget-state bridge, Drawply passes bounded annotation data, text, colors, coordinates, element IDs, transformation values, scene identity and the source path to that bridge as you edit. The host may retain it and provide it to the model. This saved reference may simplify strokes or omit marks on very large drawings; live drawing and image export retain full detail. Reloading can restore only the compact reference.
Exported PNGSave drawing creates a file through your browser or host’s download mechanism. It is not automatically attached to a conversation by Drawply.
Chat & attachmentsYou send instructions and attachments through the host’s normal composer. Its privacy policy and your account settings govern that processing.

The standalone renderer and inline editor contain no Drawply-operated network endpoint or telemetry. Installing the standalone skill adds files to Codex’s skill directory; installing the plugin changes its local plugin configuration and cache. Codex may make its own service requests.

This website and demo

The supplied Drawply pages contain no advertising, analytics, remote fonts, account forms, or tracking pixels. The illustrative demo keeps your marks in browser memory; reloading clears them. Saving a drawing writes it to your device. This demo has no connection to an AI service.

Website delivery is separate. GitHub Pages records visitor IP addresses for security. Requests also necessarily send connection information to the hosting provider. GitHub’s handling and retention are described in its privacy statement. Links to GitHub are ordinary links, not embedded trackers.

Other pages on pokericabra.com may use advertising or different services. Cookies already set for that domain can accompany requests even though Drawply’s own pages do not set them. Browser site-data controls let you inspect or clear these cookies. This notice does not claim that the entire domain is free of tracking.

Your choices and retention

Do not include credentials, private client data, or images you are not entitled to share. Review files can contain the original image and local paths, so keep them out of public repositories unless you intend to publish them. Drawing over information is not a secure redaction method; the review HTML still contains the underlying image.

Delete generated review files and exported PNGs using your device’s file controls when no longer needed. Removing Drawply does not erase those files or your chat history. Use your host’s controls to manage conversations, attachments and saved state. Host retention, transfers and training settings are outside Drawply’s control; consult OpenAI’s privacy policy when using its services.

Questions and public contributions

Project information is available through the maintainer’s GitHub profile. GitHub issues, comments and contributions are public unless the interface explicitly says otherwise. Keep reports non-sensitive: never post private images, access tokens or personal data in a public report.

For access, deletion or correction of data held by an AI host or GitHub, use that provider’s privacy-request channel. This project does not offer a private support inbox or collect privacy requests through this page. That does not remove any rights or obligations that apply under local law.

Changes

Future releases may change these practices. Check the notice shipped with your version; this notice does not authorize new data collection without any notice or consent required by law.

Copying a marked image

Add to chat writes the marked PNG to the system clipboard only when you press it and the host allows clipboard access. It does not read the clipboard or paste into your conversation automatically. Other applications and your operating system’s clipboard history may retain copied content.
