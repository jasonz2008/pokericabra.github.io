Website privacy

Updated November 20, 2026

This notice covers Jason Zhong’s portfolio and the Drawply distribution pages on pokericabra.com. The Pokericabra game privacy policy and Drawply software privacy notice describe those products separately.

Optional visit statistics

If you choose Allow analytics, this website loads Google Analytics 4 to understand how visitors find and explore the work. Google receives page visits, referring website information, approximate location and device or browser information, along with cookie identifiers. This helps distinguish visits and returning browsers.

The website also measures game selections, actual gameplay-video starts, viewing milestones and completions, Steam or Google Play link clicks, résumé PDF downloads, and Drawply skill or plugin ZIP download clicks. These events describe the project or destination involved. The website removes query strings and URL fragments from the page and referrer addresses it supplies to Analytics. Known campaign labels in shared links, such as the campaign source or name, may be measured separately; other query parameters are not forwarded.

Your choice

The Google Analytics tag is blocked until you allow it. Your choice is saved in this browser’s local storage. A Do Not Track or Global Privacy Control signal defaults to no analytics unless you explicitly choose to allow it. If browser storage is unavailable, the choice may need to be made again on another page or visit.

Use to change your choice. Choosing No thanks stops this website’s measurement on the current page and clears the Google Analytics cookies it can remove. It does not delete data already collected by Google. Browser site-data controls can also clear stored choices and cookies.

Drawply content stays separate

The website analytics code does not run in Drawply’s embedded or standalone demos, downloaded skill or plugin, or generated annotation editor. It does not collect images, drawings, annotation text, clipboard contents, or files you use with Drawply. Your AI host’s handling of content is described in that host’s own policies.

Google and website hosting

This setup disables Google Signals and advertising-personalization features in the website tag and requests no advertising consent. Google processes analytics data through its service. Read Google’s Analytics privacy information and Google’s privacy policy for its data handling and available controls.

The website is hosted on GitHub Pages. Hosting necessarily involves connection information; GitHub records visitor IP addresses for security. This hosting activity is separate from the optional analytics choice and follows GitHub’s privacy statement.
