## Enable automatic market updates once

1. Put **github/market-pages.yml** at **.github/workflows/market-pages.yml** in the website repository. The ZIP also includes that ready-to-place root workflow.
2. In GitHub Settings → Pages, choose **GitHub Actions** as the publishing source. Keep the existing custom domain settings. If the current publishing folder is **docs**, set the repository Actions variable **PAGES_SITE_ROOT** to **docs**; otherwise the default is the repository root.
3. The sample push trigger uses **main**. Change that line if your default branch has another name. Run **Refresh market data and publish portfolio** once from the Actions tab and check it succeeds.

The workflow runs daily at **06:17 UTC**. It retrieves index history, 12 Overview stock histories and the 30 largest AI-list companies with their histories, excludes the current New York session, validates all prices/dates and publishes the full existing website with fresh data. It does not commit generated prices to your source branch. If retrieval or validation fails, deployment stops and the previous valid website stays available. The dates on the dashboard always show the actual data coverage; an Overview notice appears if the saved update is more than three days old.

GitHub schedules can be delayed, and public-repository schedules may be disabled after 60 days without repository activity. Keep Actions enabled and inspect failed runs. [GitHub schedule behavior](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule) · [GitHub Pages workflow setup](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).
