# Public portfolio media

The Pages workflow copies the complete `assets/` and `drawply/` trees. These are publication directories; keep private documents, raw source captures and internal evidence elsewhere.

| Location | Public use |
| --- | --- |
| `assets/keyart/` | Seven selected project key-art images, distinct from gameplay evidence. |
| `assets/projects/` | Selected real interfaces and gameplay stills; Trainee also includes its main menu. Fore of the Dead's concept image remains explicitly distinguishable from its gameplay still. |
| `assets/thumbnails/` | Landscape WebP crops for the seven-project selector. |
| `assets/videos/` | Seven actual project recordings, played on request through the native video dialog. |
| `assets/Jason-Zhong-Resume.pdf` | Public professional résumé with private contact details omitted. |
| `drawply/assets/` | The preserved independent tool's imagery, mark and self-hosted Manrope font. |

The seven video filenames are `pokericabra.mp4`, `pokericabra-trainee.mp4`, `indie-game-dev-clicker.mp4`, `backpack-pokeris.mp4`, `moba-auto-battler.mp4`, `one-more-game.mp4`, and `fore-of-the-dead.mp4`. Captions, durations, development caveats and matching screenshots are maintained in `index.html`'s `portfolio-data` JSON.

Pokericabra PC uses the approved edited gameplay trailer, not an uninterrupted session recording. Indie Game Dev Clicker Inc.'s trailer is earlier development footage and says so in the dialog. BackPack Pokeris uses a 24-second edit of the main page, loadout, selected upgrade views, one summon view and battle; the battle segment uses automatic mode. Its video URL carries a content version so browsers load the updated recording. MOBA Auto Battler and One More Game are marked as work in progress. Fore of the Dead pairs visual-direction artwork with actual demo gameplay. Never substitute generated mock gameplay for these sources.

The BackPack Pokeris edit uses an excerpt of the existing Pokericabra map BGM asset `Sound/Faded Polaroids.mp3`, with a music mix and short entrance/exit fades. The standalone track is not published. Raw recordings and the edit timeline stay outside the public asset tree.

The approved composition reference and its approval metadata remain under `.impeccable/mocks/`, outside deployment. Its invented project names, screens and claims are visual-reference material only. Do not copy them into public content.
